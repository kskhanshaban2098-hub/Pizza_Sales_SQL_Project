# 🍕 Pizza Sales Analysis — SQL Project

## 📌 Project Overview

This project analyzes pizza sales data using **MySQL** to understand order patterns, revenue, pizza performance, and customer ordering trends.

The analysis uses multiple related tables and SQL queries to extract meaningful business insights.

## 🎯 Project Objectives

* Analyze total orders and revenue.
* Identify the highest-priced pizzas.
* Find the most commonly ordered pizza sizes.
* Identify top-selling pizza types.
* Analyze sales by pizza category.
* Analyze orders by hour.
* Calculate revenue contribution.
* Analyze cumulative revenue over time.
* Identify top pizzas within each category.

## 📊 Analysis Performed

* Total Number of Orders
* Total Revenue
* Highest-Priced Pizza
* Most Common Pizza Size
* Top 5 Most Ordered Pizzas
* Quantity by Pizza Category
* Hourly Order Distribution
* Average Daily Pizza Orders
* Top 3 Pizzas by Revenue
* Revenue Contribution by Pizza Type
* Cumulative Revenue Analysis
* Top 3 Pizzas by Category
